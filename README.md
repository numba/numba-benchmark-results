# numba-benchmark-results

Benchmark result JSON files generated by the [numba-benchmark](https://github.com/numba/numba-benchmark) CI, one file per Numba commit under [`data/`](./data).

This repository is mounted at `results/` in `numba-benchmark` as a git submodule. Do not edit it by hand: the benchmark workflow adds new result files and regenerates the commit index.

See [COMMITS.md](./COMMITS.md) for the commit index.
